# Chapter 8 — Shell Scripting

Learn how to write and run simple bash scripts.

## ✅ Exercises
- Make a script executable: `chmod +x hello.sh`
- Run a script: `./hello.sh` or `bash hello.sh`
- Add variables, loops, and conditionals.
- Use `set -euo pipefail` for safer scripting.

## 📋 Example commands
```bash
cd /workspace/08-scripting
chmod +x hello.sh
./hello.sh
bash hello.sh
```
